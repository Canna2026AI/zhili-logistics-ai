# 统一术语词典

导航、状态、接口和测试必须使用本词典；别名只允许用于搜索关键词或迁移映射。

| 标准术语 | 英文/API | 禁止作为导航主名的别名 | 定义 |
| --- | --- | --- | --- |
| 运营工作台 | operations | 运营管理 | 内部员工的业务工作区总称 |
| 运单 | waybill | 订单号、物流单 | 贯穿预报、仓储、运输和结算的业务实体 |
| 订单 | order | 运单 | 客户录入意图；可生成一个或多个运单 |
| 订舱/提单 | booking / bill-of-lading | 订单提单 | 干线舱位与运输单证工作台 |
| 问题件 | issue | 问题订单、问题运单 | 与运单主状态并行的异常工单 |
| 客户门户 | customer portal | 客户端 | 客户用户的 Web 工作区 |
| 接货批次 | last-mile intake batch | 到货单 | 尾程站点接收一组运单的核对单元 |
| 派送任务 | delivery task | 派件单 | 绑定路线、执行者、时间窗和运单集合的任务 |
| 签收凭证 | POD | 签收图 | 带版本、来源和审计的不可变签收证据 |
| 预存款 | customer prepayment | 钱包充值 | 仅用于物流账单分配的客户资金 |
| 未分配收款 | unapplied receipt | 余额 | 已入账但尚未核销到账单的金额 |
| 支付订单 | payment order | 微信订单 | 发起、跟踪和对账外部支付的业务对象 |
| 状态计数器 | StateCounter | KPI 卡 | 带单位、口径、时点和筛选链接的状态汇总 |
| 代入租户 | impersonation | 登录客户 | 平台管理员限时、带原因地进入租户上下文 |

状态标签统一映射：进行中/信息用 `info`，等待处理/差异用 `warning`，成功/健康用 `success`，失败/逾期/冲突用 `danger`，关闭/取消/未知用 `neutral`。域状态不得直接引用色值。
