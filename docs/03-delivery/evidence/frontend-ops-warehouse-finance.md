# F1B 仓库、干线、轨迹客服与财务前端证据

## 完成范围

- `WH-01–08`：扫码收货、复重/量方/图片、差异、库位/盘点、分货、袋/托/柜、出库预检和打印入口。
- `LINE-01–04` / `LM-01–06`：订舱、提单、清关、FBA、尾程接货/派送/POD 与尾程费用入口。
- `TRK-01–03` / `CS-01–03`：轨迹去重乱序、人工轨迹、停滞、问题件、退件、索赔和扣放货。
- `FIN-01–10` / `PAY-01–04`：应收应付、审核/反审核、账单、支付订单、预存款/未分配收款、退款、核销、余额、汇率、分摊、期间、发票和利润回查。

## 契约与交互

- 四域客户端使用 `@zhili/contracts` 生成 `paths` 与 `@zhili/api-client`；测试校验 URL、幂等键、`If-Match` 和请求体。
- `F06-DANGER-UNREVIEW` 在确认前同屏显示下游影响、至少 5 字原因、本地/预期版本 11 和 `audit://finance/charges/CHG-S2505120004`。
- 通用状态覆盖 `NORMAL/LOADING/EMPTY/FAILED/FORBIDDEN/STALE/PARTIAL`，命令会改变前端状态并可调用注入的强类型 command port。
