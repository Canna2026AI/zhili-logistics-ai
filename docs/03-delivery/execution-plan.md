# 智立科技物流AI系统执行计划

## Global Constraints

- 严格顺序：设计与交互冻结 → 全前端 → 全后端 → 集成与验收。
- 独立品牌与源码；不得复制 T6 的商标、素材、专有文案或实现。
- 每个生产行为必须先写失败测试并观察正确失败，再写最小实现。
- 每个功能必须具有真实状态、API、持久化、权限、审计、错误态和自动测试。
- 所有租户数据同时经过应用权限与 PostgreSQL RLS；默认拒绝跨租户访问。
- 已审核财务只能反审核、冲销或调整；金额、核销和分摊满足守恒。
- AI 只自动执行策略允许的低风险动作；关键财务、扣放货、删除和敏感导出需人工。
- 前端严格匹配 `docs/01-design/concepts/` 与设计令牌，桌面宽表不得改造成卡片列表。
- 工作树位于 `.worktrees/`，分支为 `codex/*`；共享契约和最终迁移由集成负责人管理。

## Task 1: Monorepo 与工程基线

建立 pnpm/Turborepo、TypeScript、ESLint、Prettier、Vitest、Playwright、Changesets、Commitlint 与统一脚本。创建所有 `apps/`、`packages/` 和 `infra/` 入口，加入 AGPL-3.0、贡献指南、CODEOWNERS、PR 模板和 GitHub Actions。验收：Node 24 环境下 install、lint、typecheck、test 和空构建通过。

## Task 2: 代码设计令牌与核心 UI

先为令牌解析、Button、Input、StatusTag、Dialog、Drawer、DataTable 和 AppShell 编写失败测试，再实现与 `design-system.md` 同源的 CSS 变量和 React 组件。建立 Storybook 状态目录和可访问性测试。验收：默认/悬停/焦点/禁用/加载/错误状态及紧凑密度通过。

## Task 3: 公共契约与前端 Mock

定义 OpenAPI 3.1、标准错误、游标分页、Idempotency-Key、乐观锁、SSE Job 和 Webhook 类型；用 Zod 生成前端客户端与 MSW 场景。验收：正常、空、失败、无权限、过期和部分成功契约测试通过。

## Task 4: 运营端壳与主数据前端

实现登录、工作台、侧栏、多页签、保存视图、客户/联系人、组织、仓库、代理、供应商、币种、费用和权限矩阵。验收：筛选/滚动/选择状态恢复、字段脱敏和权限模拟 E2E 通过。

## Task 5: 报价、订单和运单前端

实现渠道、分区、价卡、附加费、限制、特殊价、查价解释、标准/FBA 运单、包裹品名、导入、状态列表、详情抽屉和批量命令。验收：概念图 00/01 的原生比例视觉回归和核心流程通过。

## Task 6: 仓库、PDA 与干线前端

实现收货、复重、量方、图片、库位、分货、袋/托/柜、出库、订舱、提单、报关、FBA 箱号、尾程接货/派送/POD；PDA 实现扫码广播、相机、离线队列与冲突。验收：概念图 02/06、Android 壳与弱网 E2E 通过。

## Task 7: 轨迹、客服和财务前端

实现轨迹、问题件、退件、索赔、扣放货、应收应付、审核、账单、支付订单、预存款/未分配收款、退款、核销、余额、汇率、分摊、期间和发票申请。验收：概念图 03、多币种显示、微信支付状态和危险命令交互通过。

## Task 8: 客户、平台与官网前端

实现客户门户全部页面、SaaS 租户控制台和精简官网。验收：概念图 04/05/07，桌面与移动响应式、代入警告和公开法律页面通过。

## Task 9: API、数据库与 Worker 基线

建立 NestJS API/Worker、Drizzle/PostgreSQL、Redis/BullMQ、对象存储、事务 Outbox、审计、请求追踪、健康检查、迁移与种子框架。验收：Compose 环境中 API、Worker 和依赖健康，RLS 默认拒绝。

## Task 10: 身份、租户、权限与主数据后端

实现账号密码、微信 OAuth 适配、刷新会话、租户、组织、用户、客户、设备、角色、动作、数据范围和字段策略。验收：Argon2id、会话轮换、跨租户和越权负例通过。

## Task 11: 报价、订单与运单后端

实现渠道规则 DSL、价卡版本、报价解释、利润、订单、运单、包裹、品名、附件、状态机、导入映射和批次回滚。验收：边界重量、优先级、舍入、历史快照、非法状态和幂等属性测试通过。

## Task 12: 仓库与干线后端

实现扫描事件、收货、测量、库存、库位、分货、装载、出库、订舱、提单、班次、报关、尾程接货/派送/POD、合作方同步和打印任务。验收：重复扫描、并发、撤销、扣货、POD 版本和离线补传测试通过。

## Task 13: 财务结算后端

实现费用、应收、应付、审核/反审核、锁单、账单版本、收付款、支付订单、微信支付回调、退款、核销、余额、汇率、分摊、利润、期间和发票工作流。验收：财务与支付不变量、回调幂等和 Decimal 精度属性测试全部通过。

## Task 14: 轨迹、客服、通知与报表后端

实现轨迹事件去重/乱序、问题工单、SLA、退件索赔、通知模板、企业微信、邮件、Webhook，以及业务/财务报表。验收：重复事件、超时、通知重试和报表口径对账通过。

## Task 15: 开放 API 与重点连接器

实现公共 API 客户端、作用域、限流、密钥轮换、签名、重放、死信和对账；完成 UPS、DHL、Amazon SP-API、企业微信和微信支付适配器。验收：官方沙箱或契约沙箱、超时后对方成功和人工重放通过。

## Task 16: AI 网关与自动化

实现 OpenAI 默认网关及火山、通义、DeepSeek 适配接口；实现 Excel 映射、报价解释、异常分类、客服草稿、触发器 DSL、策略内自动动作和关键审批。验收：权限过滤、策略阈值、提示版本、审计和回滚测试通过。

## Task 17: Docker、可观测与恢复

完成多阶段镜像、Compose、GHCR、配置校验、Prometheus/OpenTelemetry、日志脱敏、备份与恢复、演示种子和单租户部署模式。验收：空机器冷启动、健康检查和恢复演练通过。

## Task 18: 全量验收与发布

逐项审计全部追踪项；运行 lint、typecheck、unit、integration、Playwright、视觉、a11y、性能、安全、许可证、镜像和外部沙箱。任何失败先写回归测试再修复。验收：矩阵全部 VERIFIED，main 通过 CI，发布 v1.0.0、GHCR 和完整 GitHub 文档。
