# AppShell 与共享交互规格

本页是五端壳、抽屉、命令层级和终端画布的唯一源真相。概念图与本页冲突时，以本页为准并重出概念图。

## 1. 运营端固定槽位

1440×900 与 1920×1080 共用同一结构：48px 全局栏、36px 工作页签栏、224px 展开侧栏或 56px 折叠侧栏、剩余为工作区。工作区最小宽度 1180px；低于此宽度横向滚动，不把宽表改成卡片。

| 槽位 | 固定内容 | 可选内容 |
| --- | --- | --- |
| 全局栏左 | 品牌、租户/组织切换 | 环境标记 |
| 全局栏中 | 全局搜索 | 长任务进度快捷入口 |
| 全局栏右 | 消息、帮助、用户 | 仓库设备状态 |
| 工作页签栏 | 首页与可关闭任务页签 | 未保存点、过期标记 |
| 侧栏 | 运营工作台、主数据、渠道报价、订单运单、仓库、订舱/提单、尾程、轨迹客服、财务、报表、自动化集成、系统 | 权限过滤后的二级菜单 |
| 工作区 | 页面标题、状态计数器、工具栏、主体 | 右详情抽屉 |

全局搜索、设备、帮助、消息和用户位置不得随业务页漂移。`运营工作台` 是侧栏首页；`运单` 是任务页签，二者不互换命名。

## 2. 命令层级

- 一个页面只有一个实心主命令；其他安全动作使用次按钮或文本动作。
- 下单页主命令为“提交预报”。“直接收货”只对具备 `warehouse.receive.direct` 的用户显示在更多菜单，执行前运行预检并明确将同时创建预报、收货、测量和费用草稿。
- 收货未完成时，仓库页主命令为“确认收货”；确认后页面进入分货阶段，主命令才变为“确认分货”。
- 审核、反审核、核销、退款、放货、删除、敏感导出和 AI 关键写入必须显示影响、原因、权限、版本和审计去向。
- 非法状态迁移既在 UI 禁用，也由 API 返回 `STATE_TRANSITION_NOT_ALLOWED` 与允许动作列表。

## 3. Drawer

Drawer 只有 480px 快速查看和 640px 复杂查看两档。结构固定为 Header、可选 Subheader、可选 Tabs、Scrollable Body、Sticky Footer；关闭按钮和标题位置固定。打开后 URL 带资源 ID，Esc 关闭并恢复触发点焦点；有未保存修改时先确认。

## 4. DataTable 与 StateCounter

`DataTable` 使用服务器游标分页、排序和结构化筛选。列管理、保存视图、共享视图和筛选标签是共享能力；“本页选择”和“全部结果”必须二次明确。大数据状态使用虚拟行和异步全量操作，不把百万行加载到浏览器。

`StateCounter` 属性固定为 `label/value/unit/asOf/filterQuery/visibility`。点击必须产生可见筛选标签；金额统计显示币种和口径，数量统计显示业务对象，平台用量显示计费窗口。

## 5. 五端画布与密度

| 终端 | 设计基线 | 密度与导航 |
| --- | --- | --- |
| 运营端 | 1440×900、1920×1080 | 高密宽表、固定侧栏、多页签 |
| 客户门户 | 1440×900、390×844 | 任务优先，中密；移动端底部导航 |
| PDA | 390×844 | 单手触控、48px 以上主触点、始终可见离线状态 |
| SaaS 平台 | 1440×900 | 高密租户表、全局范围和代入横幅 |
| 官网 | 1440×900、390×844 | 独立营销插画，产品 CTA 使用纯色按钮 |

## 6. 平台代入

代入后五端顶部显示不可关闭的身份横幅：目标租户、管理员、原因、剩余时间和“立即退出”。禁止修改平台自身权限、延长当前会话或隐藏审计。超时后当前命令失败为 `IMPERSONATION_EXPIRED`，保留表单草稿并安全返回平台端。

## 7. 图标、圆角、颜色和阴影

产品 UI 只使用统一线性图标；官网插画单独管理。业务控件圆角 4–6px，容器上限 8px；PDA 触控卡可到 12px。主操作只使用纯色 teal，业务页面不使用装饰性渐变。阴影只用于 Drawer、Dialog、Popover 和浮层，其余层级使用边框。
