# 五端页面与状态矩阵

每个页面必须设计：正常、加载、空、失败、无权限、数据已变化、部分成功、危险确认；列表额外包含大数据、长文本和字段脱敏状态。

## 客户门户

登录/微信登录、客户工作台、新建/复制运单、Excel 导入、查价与报价结果、运单列表/详情、轨迹、附件、问题工单、账单、付款记录、余额、发票申请、联系人/地址簿、API 申请和安全设置。

## SaaS 平台端

## 精简官网

首页、产品能力、安全与部署、登录入口、隐私政策、服务条款和开源许可证。

## 必须可点击验证的流程

1. 客户下单 → 地址/限制/报价 → 预报 → 仓库扫码收货。
2. 多渠道查价 → 查看解释 → 选择渠道 → 保存报价版本。
3. 收货差异 → 问题工单 → 补资料 → 恢复分货。
4. 运单加入订舱/提单/柜 → 兼容性检查 → 出仓。
5. 轨迹停滞 → 自动建问题件 → 分派 → 通知客户 → 关闭。
6. 应收生成 → 审核 → 账单 → 收款 → 部分/全部核销。
7. 应付导入 → 差异 → 对账 → 付款 → 利润回查。
8. 配置权限 → 预览最终权限 → 以用户视角验证。
9. PDA 断网扫描 → 本地排队 → 重启 → 恢复同步 → 处理冲突。
10. AI 识别 Excel → 映射建议 → 自动应用低风险字段 → 人工确认关键写入。
