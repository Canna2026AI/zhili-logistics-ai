## 校验规则

- 重量、尺寸、金额和百分比必须由 Decimal 公式计算，不在 UI fixture 中手写派生值。
- 时间用 ISO 8601 保存并携带来源时区，截图默认 `Asia/Shanghai`。
- 视觉样例中的运单号、报价号、账单号、客户和金额跨端一致。
- 故意异常数据放在独立 failure fixture，并明确期望错误码；不得污染正常态基准。
