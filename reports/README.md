# T6 竞品调研交付索引

调研日期：2026-07-22

1. [T6 竞品深度调研总报告](./2026-07-22-T6-竞品深度调研总报告.md)  
   给决策者和产品负责人：结论、定位、产品版图、复刻策略、工期、风险、验收与待确认问题。
2. [T6 功能架构报告](./2026-07-22-T6-功能架构报告.md)  
   给产品和研发：角色权限、领域对象、状态机、财务不变量、模块功能和实施切片。
3. [T6 交互与视觉报告](./2026-07-22-T6-交互与视觉报告.md)  
   给产品和设计：全局框架、列表/表单/扫描/财务/权限交互、视觉基线和可用性验收。
4. [ChatGPT Web Research 原始提取](./2026-07-22-t6-chatgpt-web-raw.md)  
   第二路线上的独立研究原文，用于证据追溯；正式结论以经过逐页复核的前三份报告为准。

## 建议阅读顺序

先读总报告的“结论先行”和“学习与复刻路线”，确定要做的商业范围；再由产品/研发评审功能架构的 P0 闭环；最后按交互报告完成高保真原型和任务测试。

## 重要边界

公开资料能充分支撑产品范围和主要操作路径，但不能证明真实生产环境中的价格、性能、SLA、全部权限、异常态和数据隔离。正式立项前应取得合法演示账号、正式报价和合同资料，补做多角色沙盒验证。
